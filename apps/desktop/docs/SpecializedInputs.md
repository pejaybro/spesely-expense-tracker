# Specialized Inputs

These components inherit all layout, floating, and dark-aesthetic features from the base `Input`.

## Included Components
*   **NumberInput / AmountInput**
*   **PhoneInput**
*   **EmailInput / PasswordInput**

## Shared Upgrades
All specialized inputs now support the following streamlined standards:
| Prop | Values | Description |
| :--- | :--- | :--- |
| `isFloating` | `boolean` | Enables the floating label effect. |
| `labelAlign-X` | `"left" \| "center" \| "right"` | Horizontal alignment. |
| `labelAlign-Y` | `"top" \| "middle" \| "bottom"` | Vertical positioning. |
| `variant` | `"curved" \| "rounded" \| "square"` | Permanent dark border styles. |
